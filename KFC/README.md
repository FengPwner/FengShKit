# 🍗 KFC — 终端“肯德基”矩阵屏保

一个纯娱乐的 Bash 小玩具：让 `KFC` 和 `肯德基` 两个词像黑客帝国代码雨一样，铺满整个终端屏幕循环滚动。

## 特性

- **全屏矩阵雨**：自动读取终端行列数，用 `KFC` / `肯德基` 填充并持续下落，随机换词
- **疯狂星期四彩蛋**：当今天是**周四**且设备位于**中国时区**（Asia/Shanghai 等或 UTC+8）时，自动调用 `xdg-open` / `open` / `start` 打开肯德基全球官网 https://global.kfc.com
- **干净退出**：按 `Ctrl+C` 恢复光标并清屏退出，不留残影

## 运行

```
bash KFC.sh
```

或赋予执行权限后运行：

```
chmod +x KFC.sh
./KFC.sh
```

## 说明

- 需要支持 `tput`（几乎全部终端都支持，Termux 需安装 `ncurses-utils`）
- 周四之外运行，它就是一个单纯的动画屏保，不会打开任何网页
- 时间判断依赖系统时区，请确保设备时区设置正确
- 想退出随时 `Ctrl+C`
