# 原神安装器-自适应

这是一个基于 Shell 和 Python 的自动化安装辅助工具，旨在帮助玩家一键下载并安装《原神》。脚本支持跨平台运行，能够自动识别当前操作系统和处理器架构，并下载对应的官方安装包。


## 核心特性

跨平台支持：完美兼容 Windows (Git Bash/WSL) 和 Android (Termux) 环境。

智能架构识别：自动检测设备处理器架构（x86_64 或 ARM64），下载匹配的安装包。

动态脚本生成：在 Windows 环境下，自动构建并唤起  .bat  批处理脚本执行下载任务。

自动唤起安装：下载完成后，在 Android 设备上自动唤起系统安装界面；在 Windows 上自动打开启动器安装程序。

未知系统兜底：当运行于不支持的系统时，等待 5 秒后自动跳转至《原神》官方网站。

原生 Python 验证工具：附带纯原生库编写的 URL 验证脚本，无需第三方依赖即可检测下载链接有效性。


##  文件结构

 Install_CN.sh ：主安装脚本，负责环境检测、下载与安装唤起。

 test_CN.py ：链接验证工具，用于在安装前检查官方 API 是否有效。

 README.md ：项目说明文档。


##  快速开始


1. 验证下载链接（可选）

在运行安装脚本前，建议先验证官方链接是否可用：
```
python test_CN.py
```

2. 运行安装脚本

赋予脚本执行权限并运行：
```
chmod +x Installer_CN.sh
./Install_CN.sh
```

## 运行逻辑说明

Windows 环境：检测到``MINGW``、``CYGWIN``或``MSYS``时，生成 ``Genshin_Windows_Installer.bat``并在独立窗口中自动运行，下载 PC 版启动器。

Linux / Android 环境：检测到Linux时，根据  ``uname -m``  的返回值判断架构。x86_64 下载 PC 启动器，ARM64 下载 Android APK，并在下载后通过``am start``唤起安装界面。

其他系统：无法识别的系统将触发兜底逻辑，提示并跳转至 [米哈游](https://ys.mihoyo.com/)


## 注意事项

权限：在 Android 上自动唤起安装界面时，请确保已在系统设置中允许“安装未知应用”。

启动器限制：脚本仅自动下载并打开“启动器安装包”。完整的几十 GB 游戏资源需要玩家在启动器内手动点击下载。

安全警告：请勿修改脚本中的官方 API 链接，避免下载到被篡改的恶意文件。
