# FengShKit

A lightweight collection of Shell / Python tools, built mainly for **mobile (Termux) and cross-platform** scenarios — covering everyday system maintenance, automated installation, and a bit of terminal fun. Every tool ships with its own documentation.

> Note: this repo keeps things light, readable and ready-to-run.

## Tools

| Tool | Folder | What it does |
| --- | --- | --- |
| 🎮 Genshin Impact Installer | [`GenshinImpactInstaller/`](https://github.com/FengPwner/FengShKit/tree/main/GenshinImpactInstaller) | Detects your OS and CPU architecture, then downloads and launches the official Genshin Impact installer with one command |
| 🍗 KFC | [`KFC/`](https://github.com/FengPwner/FengShKit/tree/main/KFC) | A full-screen "KFC / 肯德基" matrix-rain terminal toy |
| 🛠 System Repair | [`SystemRepair/`](https://github.com/FengPwner/FengShKit/tree/main/SystemRepair) | Cross-platform system diagnostics & repair scripts: Termux / Linux / Windows / macOS |

## Requirements

- Bash (`git bash` / WSL / Termux / macOS / Linux)
- Python 3 (only needed by the link-verification helper in the Genshin installer)
